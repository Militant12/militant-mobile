# Changelog

Toutes les modifications notables de ce projet seront documentées dans ce fichier.

Le format est basé sur [Keep a Changelog](https://keepachangelog.com/fr/1.0.0/),
et ce projet adhère au [Semantic Versioning](https://semver.org/lang/fr/).

## [1.0.0] - 2026-01-30

### Ajouté
- Écran de bienvenue avec logo Militant
- Sélection d'instance avec URL personnalisable
- WebView intégrée pour navigation dans l'application
- Sauvegarde de l'URL du serveur avec SharedPreferences
- Support Android avec icône personnalisée
- Thème sombre avec couleurs du projet
- Navigation fluide sans ouverture de navigateur externe

### Fonctionnalités
- Connexion à n'importe quelle instance Militant
- URL par défaut : https://militant.revlibertaire.com
- Interface native Flutter
- Chargement automatique du dernier serveur utilisé

### Technique
- Flutter 3.0+
- Dart 3.0+
- Dépendances : webview_flutter, shared_preferences, flutter_svg
- Support Android API 21+
- CI/CD GitLab configurée
